# CMOR 438 – Machine Learning Algorithms  
Rice University

## Course Description

This repository contains implementations, unit tests, and example notebooks developed for **CMOR 438: Machine Learning Algorithms** at Rice University.

The course focuses on building a strong foundation in machine learning by implementing core algorithms from scratch and applying them to real datasets. Emphasis is placed on understanding the mathematical principles behind each algorithm, optimization methods, and practical considerations such as model evaluation and visualization.

Course topics span **supervised learning**, **unsupervised learning**, and **optimization-based methods**, with Python-based implementations and end-to-end example workflows.

## Repository Description

This repository serves as a shared codebase for machine learning algorithms implemented throughout the course. Each algorithm is implemented in Python under a unified library (`rice_ml`) and is accompanied by:

- Clean, modular source code
- Unit tests validating correctness and numerical behavior
- Example Jupyter notebooks demonstrating full workflows, including data exploration, preprocessing, training, evaluation, and visualization

The programming language used in this repository is **Python 3**.

---

## Algorithms Implemented

### Supervised Learning

- K-Nearest Neighbors (KNN)
- Linear Regression
- Logistic Regression
- Perceptron
- Multilayer Perceptron (Neural Network)
- Decision Trees
- Regression Trees
- Ensemble Methods

### Unsupervised Learning

- K-Means Clustering
- Principal Component Analysis (PCA)
- DBSCAN
- Community Detection

---

## Example Notebooks

The example notebooks included in this repository are designed to illustrate **complete machine learning pipelines**, rather than isolated function usage. Each notebook typically includes:

- Dataset loading and exploration
- Feature preprocessing
- Model training and optimization
- Quantitative evaluation (e.g., accuracy, RMSE, ROC/AUC)
- Visualizations for interpretation and analysis
